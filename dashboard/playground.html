Decision model: CPU vs GPU

The Semantic Router runs a small 0.3B decision model (vllm-sr/Vela-2.0-0.3B) to pick the tier for every prompt. This runs the exact same model and code on the CPU and on the AMD MI300X, changing only the device, and compares how many routing decisions per second each can sustain. Nothing is simulated; the numbers below come from a real run.

Measured on the transformers (PyTorch, fp32) reference path so the device is the only variable. The production router classifies on CPU with a compiled, optimized runtime that is much faster than this fp32 CPU path; this panel isolates the raw model forward to show the GPU acceleration.
